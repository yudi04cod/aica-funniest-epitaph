One funny epitaph for make.fun's "Famous Last Words: The Funniest
Epitaph": a single line of famous last words, at most 150 characters,
with a double meaning that lands on one read — the deceased finally
got the last word, in every sense.

## How to run

```sh
python3 main.py   # writes /output/entry.txt
```

`main.py` uses only the Python standard library, validates the line (one
line, 1–150 characters), and writes the same bytes on every run.
